## 数据库记录的覆盖与读取

`databases/thread_history_1/thread_items.jsonl.gz` 导出的 664 条 `userMessage` 与 1368 条 `agentMessage`（共 2032 条）均在同线程的 JSONL 快照中找到相同文本；比较仅统一换行并去除首尾空白。现有线程 Markdown 已覆盖这些消息，没有额外追加重复阅读版。比较证据见 [`../metadata/conversations/database_message_coverage.json`](../metadata/conversations/database_message_coverage.json)。

该对照针对文本；图片等非文本 content 块仍保留在原始 JSONL 与数据库 item_json 中。

该 gzip 文件每行是一个外层 JSON 记录，字段包含 `thread_id`、`turn_id`、`item_id`、`rollout_ordinal`、`created_at_ms`、`item_type`、`item_json` 等。`item_json` 是 JSON 字符串，需再次 `json.loads()`；`userMessage` 的文本在 `content[*].text`，`agentMessage` 的文本在 `text`。其他 `item_type` 还包含命令执行、文件修改、推理摘要、上下文压缩、子 agent 活动及图片查看，可通过同样的二次解码方式读取。

```python
import gzip
import json

path = "conversations/databases/thread_history_1/thread_items.jsonl.gz"
with gzip.open(path, "rt", encoding="utf-8") as records:
    for line in records:
        row = json.loads(line)
        item = json.loads(row["item_json"])
        # 按 row["thread_id"] 或 row["item_type"] 筛选，再读取 item。
        print(row["thread_id"], row["item_type"], item)
```

线程元数据位于 `databases/state_5/threads.jsonl.gz`；回合状态及时间位于 `databases/thread_history_1/thread_turns.jsonl.gz`。数据库完整表 schema、源行数、导出行数及事务时间见 [`databases/manifest.json`](databases/manifest.json)。仅数据库元数据可用的线程会在上方索引标注。
