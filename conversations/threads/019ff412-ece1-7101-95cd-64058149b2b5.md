打上 `--enable-test-pd-without-transfer` 后，**请求的 URL、HTTP 方法和原本协议不变**，只是每个 JSON 请求体顶层增加两个字段：

```json
{
  "bootstrap_host": "2.2.2.2",
  "bootstrap_room": 1234567890
}
```

其中：

- `bootstrap_host` 固定为字符串 `"2.2.2.2"`
- 正式压测时，`bootstrap_room` 是每个请求随机生成的 10 位整数
- 目的是给每个请求一个独立的 bootstrap room，并使用不可实际传输的目标地址，从客户端侧触发“只测 Prefill 或 Decode、不进行 KV 传输”的测试形式

### 默认 `sglang` 后端

```http

```


### 一个值得注意的细节

预热请求和正式压测请求不同：

```text
预热请求：bootstrap_room = "0"         字符串
正式请求：bootstrap_room = 10位随机数   整数
```

初始化发生在 [bench_serving.py](/sgl-workspace/llm-benchmark-online/bench_serving.py:1906)，正式请求会在循环中覆盖成随机整数，见 [bench_serving.py](/sgl-workspace/llm-benchmark-online/bench_serving.py:1657)。

因此实际调用链可以概括成：

```text
命令行标志
   ↓
extra_request_body 加入 host="2.2.2.2", room="0"
   ↓
预热请求直接使用 room="0"
   ↓
正式请求复制 extra_request_body
   ↓
为每个请求把 room 覆盖为随机 10 位整数
   ↓
字段合并到 /generate 或 OpenAI 请求体顶层
```

另外，`--pd-separated` 虽然也被传进了 `benchmark()`，但目前函数内部没有使用它；这个标志本身不会进一步改变请求。
