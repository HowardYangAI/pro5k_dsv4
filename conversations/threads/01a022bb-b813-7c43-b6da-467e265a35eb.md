```text
→ TokenizerManager._handle_batch_output()
→ SSE 增量或最终 JSON
```

- KV 只在 P/D 节点之间传输。
- 客户端收到的是文本/token/统计或错误，不会收到 KV。
- Decode 不重新处理完整 8K Prompt；它接收 Prefill KV 和 handoff token 后继续生成。

修复后的 KV 压力分流：

```text
supports_cpu_copy()
→ CPU save/resume

真实 PD 且 supports_pd_rebootstrap()
→ 回 Prefill 重算前缀，再传 KV

Fake PD / 不可安全重算
→ AbortReq，仅终止该请求，服务不崩溃
```
